Ooredoo Tunisia
Bill Generation Solution
Request for Proposal

Abstract: The purpose of this RFP is to solicit responses from identified vendors to provide a bill generation
solution based on the requirements identified in this document.
All information in connection with this RFP and project is strictly confidential.

1.0 About Ooredoo Tunisia
Ooredoo Tunisia is a private telecommunications company in Tunisia. Set up with capital of 330
million Tunisian dinars, it was founded on 11 May 2002. Ooredoo Tunisia is part of the Ooredoo Group.
It is the largest operator in Tunisia.
Ooredoo Tunisia has also won, for the fourth consecutive year, the Best Customer Service Telecommunications Sector award.

2.0 Definition and Scope
Bill Generation solution is a core component in Ooredoo Tunisia billing system. The role of this entity is to
produce customer bills in PDF format.
Facing the new customer requirements, Ooredoo Tunisia targets to renew the bill generation solution.

2.1 The Bill design
The current bill design did not change since years. For customer satisfaction, new design is requested.

2.2 The Technical solution
The current bill generation solution has several limitations:
- Slowness of document generation process
- Complexity of design changes implementation: Any change requires a hardcoded update.

3.0 Goals and Objectives
Ooredoo requires an industrialized IT solution (standard, preconfigured, fully automated, scalable and reliable solution).
1. Functional area:
- Modify the bill design to fit the business requirements
- Have a rich and complete bill by supporting any future bill design changes
- Faster time to market by providing full automation and full integration capabilities

2. Technical Area:
- Provide graphical interactive interface for bill design customization
- Produce unified XML file for each bill
- Insert bill details in Data Base tables (needed for statistics)
- Produce bill in PDF Format
- Send bills by email
- Produce and send call details in CSV Format
- Create a single PDF bill for several invoices (for splitted large accounts)
- Provide web application for proposed solution management

3.1 Main Pain Points
1. Technical limitation and lack of flexibilities for extensions and evolutions of bill design
2. Performance issues:
   a. PDF bill generation very slow (20k bills per Hour)
   b. High usage of server resources (CPU/Memory)
3. Splitted Large account bill generation
